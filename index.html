How the analysis works

We analyze luminance gradients at multiple crops and scales. We ignore low-gradient “flat” pixels by keeping only pixels above a gradient magnitude percentile, then compute gradient covariance and a PCA-style anisotropy score.

Tip: Use multiple images for calibration; don’t rely on a single score.
